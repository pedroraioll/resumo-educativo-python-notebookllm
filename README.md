# Estruturas de Dados em Python com NotebookLM
## Contexto

O assunto de interesse escolhido para este caderno temático foi estruturas de dados em Python, com foco em listas, dicionários, tuplas, conjuntos e funções.

A escolha desse tema se deve à importância desses conceitos para a programação em Python. As estruturas de dados permitem organizar, armazenar e manipular informações de diferentes formas, enquanto as funções ajudam a criar códigos mais organizados, reutilizáveis e fáceis de manter.

O NotebookLM foi utilizado como ferramenta de apoio ao estudo, permitindo reunir diferentes fontes sobre o tema e utilizá-las para gerar explicações, comparações, exemplos e materiais de revisão.

## Objetivos de estudo

Com este material, os principais objetivos são:

- Compreender o funcionamento de listas, tuplas, dicionários e conjuntos em Python;
- Identificar as principais diferenças entre essas estruturas de dados;
- Entender em quais situações cada estrutura é mais adequada;
- Aprender as principais operações realizadas com cada estrutura;
- Compreender como criar e utilizar funções em Python;
- Praticar os conceitos por meio de exemplos e exercícios;
- Utilizar o NotebookLM como ferramenta de apoio para organizar e revisar o conteúdo estudado;
Desenvolver uma base sólida nesses conceitos para aplicá-los em problemas de programação mais complexos.
